# Duskhallow theme

A spooky look for the Claude Code desktop and mobile apps.

- **Dark mode:** a violet-black moonlit night. Links glow ghost-green, errors are Blood Moon red, success is herb green, warnings
  are lantern amber, and special highlights are witchcraft violet.
- **Light mode:** the same valley at dusk, wrapped in lavender fog.
- **Animated background:** a full moon that now and then turns into a Blood Moon, a gothic chapel and lamp-lit houses with
  flickering windows, a graveyard with a ghost that drifts by, a witch's cottage on stilts with chimney smoke, a jack-o'-lantern,
  glowing rune stones, drifting fog, bats and fireflies. The middle and bottom of the screen stay quiet so your conversation stays
  easy to read. Motion stops if your system asks for reduced motion.

The terminal and editor extensions don't draw themes, so it shows in the apps only.

## Install

At the prompt of a terminal session:

```
/plugin install duskhallow-theme --marketplace Aniond/duskhallow-theme
```

From a shell:

```bash
claude plugin install duskhallow-theme --marketplace Aniond/duskhallow-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with
`Aniond/duskhallow-theme`, then Add plugin.

Answer `y` to add the marketplace, then pick a scope (user scope applies it to every session). The theme appears in sessions
started after the install.
